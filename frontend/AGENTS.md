# Frontend Agent Rules

## Scope

Work mainly in /frontend.

You may read:
- /backend
- /docs/API_CONTRACT.md
- /docs/PRODUCT.md
- /docs/SCREEN_FLOW.md
- /DESIGN.md

Do not modify backend files unless explicitly instructed.

## Rules

- Follow DESIGN.md for UI direction.
- Adapt the design to a cute study pet game.
- Follow docs/API_CONTRACT.md for API shapes.
- Keep API-related functions separated so backend integration is easy later.
- Add loading, error, and empty states.
- Make surgical changes only.
- Do not add new libraries unless necessary.
- Do not rewrite unrelated files.

## Done Criteria

- Frontend builds or typechecks.
- Main mock demo flow works.
- Changed files are summarized.
